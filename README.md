# Sprach-Arena – Deutsch 10

Interaktives Lernmodul für die 10. Klasse zu Sprache, Rechtschreibung und Zeichensetzung:
Schachtelsätze, Synonyme & Textkohärenz, Redewiedergabe, Fehlerdiagnose, Getrennt-/Zusammenschreibung,
Groß-/Kleinschreibung, Kommasetzung und das/dass – mit drei Niveaus (Anfänger, Mittelfeld, Experte),
XP-System, Abzeichen und Abschlusstest.

Website: https://stinagladow.github.io/spracharena/
